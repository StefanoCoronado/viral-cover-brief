# Descripción visual detallada — rama genérica

Se usa cuando no tienes un sistema de marca fijo (o prefieres no usarlo para esta pieza). Reemplaza al prompt de imagen (`01-plantilla-prompt-imagen.md`). Armas el prompt para la herramienta que uses (ChatGPT, Midjourney, etc.) tú mismo — esta descripción tiene que poder leerse sin inferir nada.

**Nunca reproducir texto ni diseño del post de referencia** — mismo principio que la rama con sistema propio: se describe el *mecanismo* visual, no se copia el post.

## Estructura (siempre en puntos, nunca párrafo corrido)

```
COMPOSICIÓN:      Distribución de elementos en el canvas — qué ocupa
                   cada tercio, dónde está el punto focal.

ENCUADRE:         Plano (cerrado/medio/abierto), ángulo de cámara,
                   proporción del formato (1:1, 3:4, 9:16 — los únicos
                   que soporta Google Flow).

ILUMINACIÓN:      Dirección, calidad (dura/suave), temperatura de color.

COLORES DOMINANTES: 2-4 colores concretos (no genéricos tipo "azul" —
                   describir el tono: "azul eléctrico saturado",
                   "crema cálido apagado").

TEXTURAS:         Superficies, materiales, grano, si es plano o con
                   profundidad/relieve.

ELEMENTOS GRÁFICOS: Formas, iconografía, tipografía si es parte de la
                   composición (no el copy final, solo su rol visual —
                   ej. "bloque tipográfico grande ocupando 40% inferior").
```

## Reglas

- Cada punto es una descripción objetiva de lo que se ve, no una interpretación de intención de marca.
- Sin paleta de marca específica acá — esa identidad la resuelves después, con tu propio proceso de tipografía/paleta. Un personaje/mascota es la excepción: si lo pides para esta pieza, se describe como cualquier otro elemento gráfico de la composición (posición, escala, mirada).
- No se genera un prompt de imagen ni ningún prompt cerrado — es input crudo para que armes tu propio prompt en la herramienta que uses.

## Salida esperada (formato del brief, rama genérica)

```
SISTEMA:      Genérico (sin sistema de marca fijo)
MECÁNICA:     [1-2 líneas, qué hace que el post pare el scroll]
DESCRIPCIÓN VISUAL:
  COMPOSICIÓN:        [...]
  ENCUADRE:           [...]
  ILUMINACIÓN:        [...]
  COLORES DOMINANTES: [...]
  TEXTURAS:           [...]
  ELEMENTOS GRÁFICOS: [...]
HANDOFF:      → tu propio proceso de tipografía, paleta y layout
```
